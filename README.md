A modular, high-performance haptic driver designed for wearable applications.

This project tackles a real problem in wearable design: consistent, low-latency, and power-efficient haptic feedback across different form factors and devices. Using the DA7281 haptic driver, WHCM supports both LRA and ERM motors, providing precise vibration control optimized for battery-constrained devices.

Key Features

Universal Motor Support: LRA and ERM selectable for premium or cost-effective wearables.

Flexible Connectivity: BLE for wireless integration, optional I²C/SPI for host control.

Power-Aware Design: Works with varying Li-Po battery sizes; separate rails for MCU and haptics driver.

Expandable Platform: Pads for touch sensors or IMU integration without redesign.

Firmware Abstraction: Simple API for pattern, intensity, and duration — adaptable for different wearable experiences.
